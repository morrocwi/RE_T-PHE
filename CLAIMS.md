# CLAIMS — evidence ledger for the TIMA/FIMA 2026 abstract

One row per statement that a critical reader could dispute. Each row records the **type of
evidence** behind the statement, using standard medical-science categories, and what would be
needed to strengthen it. This ledger exists so the abstract is never cited as stronger than it is.

## Evidence categories used

| Category | Meaning here |
|---|---|
| **External guideline / framework** | Published by an external body (e.g. WHO). The abstract cites it; this repository does not re-derive it. |
| **Organisational report** | A figure or procedure reported by the implementing organisation (ARAYA Nikah). Not independently audited in this repository. |
| **Conceptual synthesis / expert opinion** | Practitioner-led reasoning from documents. In standard evidence hierarchies this is the lowest level; it generates hypotheses, it does not test them. |
| **Proposed, untested** | A programme component, outcome domain or criterion put forward for prospective evaluation. No data yet. |
| **Normative / ethical position** | A statement of what ought to be done, grounded in ethics or safeguarding practice rather than in outcome data. |

## Reading rule

When citing this abstract elsewhere, cite it as **a programme theory proposed for prospective
testing**. Do not cite it as evidence that premarital health education prevents intimate-partner
harm; that evidence does not yet exist in this programme.

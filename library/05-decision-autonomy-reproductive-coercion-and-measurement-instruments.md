*Limits stated by the searcher:* This search covered PubMed only, via NCBI E-utilities, using English-language query terms; PubMed's syntax auto-expansion sometimes broadened queries unpredictably (e.g., an OR-joined multi-country query returned ~250,000 hits), which was corrected using quoted-phrase and AND-only reformulations in a second query round. Thai-language and Thailand-specific instrument-validation literature, if published outside PubMed-indexed journals (e.g., Thai regional journals, grey literature, unpublished TIMA/FIMA proceedings), would not have been captured. Only abstracts (not full texts) were read; effect sizes, full psychometric tables, and methodological details beyond what is reported in the abstract were not independently verified. No WHO/UN/Cochrane/USPSTF global guidance documents specific to decision-autonomy measurement instruments were identified as directly relevant to this angle and none are cited above; this angle's evidence base is drawn entirely from PubMed-indexed primary/secondary studies, consistent with the hard rule but leaving the GLOBAL-guidance side of this angle thin.

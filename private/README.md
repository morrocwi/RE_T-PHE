# private/ — git-ignored working area

Everything in this folder except this file is ignored by git (`.gitignore`: `private/*`).

Put here:

- data extracts, tables, organisational figures and their sources
- research strategy, development plans, reviewer correspondence
- manuscript drafts not yet ready for public view
- anything containing personal or participant information (which must never be committed anywhere
  in this repository, ignored or not — see `AGENTS.md` §3)

This folder is not backed up by git. Keep it on the workstation's regular backup path.
